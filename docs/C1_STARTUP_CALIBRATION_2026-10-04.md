## Selected override and destruction chain

FLT cache getter `8a8bc–8aa28` keys the tree by a raw FCSeqSpec pointer (`8a930`).
It inserts/balances a node before invoking the initialization callable through
virtual+30 (`8a99c`). Node+28/+30 holds a shared owner of a heap shared-pointer
wrapper; this wrapper owns the scoper. Factory failure/cold cleanup
`a5368–a53b8` releases the returned wrapper/scoper if present; this is not a
transaction for the installed-effect registry. The selected body has no mutex
acquisition; caller/context serialization remains a separate unknown.

`GetOverrideSequenceData` `8aa28–8ab40` copies the cached leaf scoper owner,
releases that temporary owner, then reads scoper+8 at `8aad8`. SetOverride
`8ab40–8ac64` likewise releases a temporary copy before writing scoper+8
at `8abf8`. This does not by itself make the scoper dead: the enclosing cache
retains the wrapper/scoper. It does require that cache/state and its dependencies
remain valid, and that concurrent mutation/reentry be covered.

Render-state destruction `142b0–142e8` calls tree destruction `14320–143a0`.
Each node releases owner+30 before deletion. Last-owner wrapper release
`8acac–8ad1c` releases the nested scoper owner and deletes its heap wrapper.
The previously checked leaf scoper destructor still uses a raw SequenceData
pointer to perform setdown. The raw FCSeqSpec cache key and raw SequenceData link
are not made independently owned by this nested cache. Full ordering between
state destruction, sequence destruction, callbacks and factory/module lifetime
is therefore PARTIAL, not an assertion that retaining one owner solves all safety.

Rechecked FCSpec destructor `5cc64–5cd3c` releases routine owner+c8 after local
tree/string/mutex destruction. PLUG ASL owner destructor `e6c0–e720` decrements
the owner and dispatches its last-owner virtual destructor; this does not identify
every module deleter, callback target or conditional unload consumer.

Complete reused FiltSetup `8d250–8ef8c` contains multiple AddEffect branches,
post-setup callbacks and a later lazy-globals path. Its local unwinding is not
evidence of global installed-map/vector/index or canonical-factory compensation.
The prior preference failure after writer mutation and non-gating notify byte
remain unresolved. A zero return, lock release or three successful windows are
not a proved complete publication boundary. Do not call this writer late yet.
